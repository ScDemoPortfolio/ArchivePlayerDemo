# Notify Frontend

This is the React-based frontend for the Notify music streaming application.

## Getting Started

### 1. Prerequisites

* Node.js (v16 or higher recommended)
* The Notify Backend server running on `localhost:8080`

### 2. Installation

Navigate to the project directory and install the necessary packages:

```bash
npm install
```

### 3. Running the App

Start the Vite development server:

```bash
npm run dev
```

The application will be available at http://localhost:5173.
